# Changelog

## [0.1.0] - 2026

- Prepared the first SoftwareX-oriented source release of Lake Semantic Cube.
- Added Base Zarr construction utilities for synthetic arrays and Changtan EFDC hourly GeoTIFF workflows.
- Added JSON semantic rule parsing, evaluation, segment detection, and Semantic Zarr writing.
- Added ODC-compatible product and dataset YAML generation and optional `datacube` CLI registration.
- Added point semantic query, actual-depth query, and regional semantic thickness query workflows.
- Added Streamlit and Flask local interfaces for project, rule, catalog, point-query, and region-query workflows.
- Added automated pytest coverage for the synthetic demo and core query chain.
